# F1PRO — Ideas into things.

Independent creative/product studio portfolio, spanning **physical products, hardware, software, board games and video games**.

## Website

This is a lightweight, single-file responsive website. Open `index.html` in a browser to preview. No dependencies or build process required.

### Publishing with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main**, folder **/(root)**, and click **Save**.
4. After GitHub finishes publishing, the address will be **https://perdido101.github.io/f1pro/**.

GitHub Pages must be enabled in repository settings. A Git commit alone does not activate hosting.
